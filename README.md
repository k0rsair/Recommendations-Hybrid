# 📚 Система рекомендаций книг

Гибридная система рекомендаций книг, объединяющая несколько подходов машинного обучения для персонализированных рекомендаций. Проект реализует полный цикл разработки рекомендательной системы: от подготовки данных до оценки и оптимизации моделей.

## Описание проекта

Система рекомендаций книг использует гибридный подход, комбинирующий:
- **Коллаборативную фильтрацию** (Item-based CF, SVD)
- **Контентные методы** (TF-IDF на основе тегов и жанров)
- **Модель популярности** (базовая рекомендация)
- **Адаптивные веса** в зависимости от типа пользователя (новые/активные)

Система автоматически адаптируется к типу пользователя:
- **Новые пользователи** (< 5 оценок): больше веса на популярность и контентные рекомендации
- **Среднеактивные** (5-20 оценок): сбалансированные веса
- **Активные пользователи** (> 20 оценок): больше веса на коллаборативную фильтрацию

## Основные компоненты

### Классы моделей

1. **PopularityRecommender**
   - Рекомендации на основе популярности книг
   - Фильтрация по минимальному количеству оценок

2. **ContentBasedRecommender**
   - TF-IDF векторизация на основе тегов и жанров
   - Косинусная схожесть для поиска похожих книг

3. **ItemBasedCF**
   - Коллаборативная фильтрация на основе схожести книг
   - Использует историю оценок пользователя

4. **MatrixFactorizationRecommender**
   - SVD матричная факторизация
   - Предсказание рейтингов для неоцененных книг

5. **HybridRecommender**
   - Объединяет все модели
   - Адаптивные веса по типу пользователя
   - Балансировка разнообразия и релевантности (MMR)

### Оптимизация весов

Функция `optimize_weights_cached()` выполняет grid search для подбора оптимальных весов:
- Составная метрика: `score = 0.6 * nDCG + 0.2 * Precision + 0.2 * Recall`
- Grid search по весам с шагом 0.1
- Использование кэша для ускорения

## Примечания

- Система автоматически определяет тип пользователя и использует соответствующие веса
- Для новых пользователей приоритет отдается популярности и контентным рекомендациям
- Для активных пользователей используются более сложные модели (SVD, ItemCF)
- Все промежуточные результаты кэшируются для ускорения работы
